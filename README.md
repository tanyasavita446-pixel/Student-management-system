# Student Management System

## About the Project
Student Management System is a Java-based console application developed to manage student records efficiently.

## Features
- Add new student
- View all students
- Search student by ID
- Update student details
- Delete student records
- Save student data using file handling
- Input validation and exception handling

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList, HashMap, HashSet
- File Handling
- Multithreading

## Project Structure
- Main.java
- Person.java
- Student.java
- StudentOperations.java
- StudentManager.java
- data/

## How to Run
1. Compile the Java files:
   `javac *.java`
2. Run the application:
   `java Main`
